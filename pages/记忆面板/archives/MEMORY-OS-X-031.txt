FILE X-031 / 远距传输链路
DISTANT TRANSMISSION

记忆通道：能量研究
记录时间：跨期资料汇编
关联对象：Trimounts Project
访问范围：REFERENCE AREA

《孤星》中的聚焦发生器与地面能量传输相联系。距离增加之后，发射端、接收端与协调工作共同决定系统表现。本卷关注链路的各个环节如何相互依赖，并将中断、偏差与恢复列为同样需要观察的状态。

记忆要点
1. 把发送、接收与控制信号放在同一时间顺序中核对。
2. 链路中断时，区分设备问题与外部条件变化。
3. 不能只用成功到达的结果评价整个传输过程。
